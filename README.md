# YatraSetu 🇮🇳
### Indian Destination Explorer & Trip Planner

**YatraSetu** is a web-based travel exploration and planning application developed as an individual college DBMS project. It brings together information about India's cultural, historical, religious, and natural destinations with indicative travel-budget estimates and itinerary-planning features.

The application helps users discover destinations, explore useful travel information, compare estimated expenses from different starting cities, and organize personalized multi-stop trips. It also demonstrates practical database concepts through a functional web interface connected to a MySQL database.

## ✨ Features

- **Destination Explorer:** Browse destinations, search by name, and filter by state or category.
- **Destination Details:** View available descriptions, visiting information, attractions, entry-fee information, and travel guidance.
- **Budget Comparison:** Compare itemized estimated expenses across Bengaluru, New Delhi, and Kolkata.
- **Trip Planner:** Create, edit, and delete trip plans; add destinations to itineraries and organize their visiting order.
- **Destination Management:** Add, view, update, search, and delete destination records, subject to database relationships.
- **SQL Reports & Analytics:** Explore destination distributions, category counts, budget statistics, above-average budget queries, and joined destination reports.

## 🗂️ Dataset

The initial dataset contains:

- **30 destinations** across Indian states and union territories.
- **30 destination-detail records** associated with the destinations.
- **90 budget-estimate records** covering 30 destinations from three starting-city origins.

The data is stored in MySQL and used by the application to generate destination listings, comparisons, itineraries, and reports.

**Budget disclaimer:** The displayed amounts are indicative prototype estimates for academic demonstration. They are not verified live fares, real-time prices, or guaranteed trip costs. Actual expenses may vary with travel dates, transport availability, accommodation, entry fees, and other conditions.

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python and Flask
- **Database:** MySQL
- **Database tools:** MySQL Server and MySQL Workbench
- **Development environment:** Visual Studio Code

## 🎓 DBMS Concepts Demonstrated

YatraSetu provides a practical demonstration of relational database concepts, including:

- Entity relationships and relational schema design
- Primary keys, foreign keys, and referential integrity
- Normalized data organization across related tables
- CRUD operations (Create, Read, Update, Delete)
- SQL joins, aggregate functions, grouping, and subqueries
- Database-driven search, filtering, and analytical reports
- Flask-based application connectivity with MySQL

## 🎯 Project Objective

The goal of YatraSetu is to combine an accessible Indian travel-planning interface with a practical implementation of database management concepts. The project demonstrates how a relational database can support destination discovery, budget comparisons, itinerary management, and SQL-based analysis through a web application.

## ⚠️ Project Scope

YatraSetu is an academic prototype intended for educational and demonstration purposes. It does not provide live fare verification, ticket booking, hotel reservations, or guaranteed travel-budget calculations.
